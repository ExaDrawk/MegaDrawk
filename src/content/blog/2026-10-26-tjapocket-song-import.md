こんにちは、Drawkです。

今回は、TJA Pocketに曲を追加する方法を紹介します。TJA Pocketは、端末にあるTJAファイルと音源を読み込んで遊ぶリズムゲームです。曲はZIPのまま取り込む方法と、解凍済みのフォルダを取り込む方法、元のフォルダを参照する方法の3通りがあります。

この記事では、ZIPから取り込む手順を中心に、つまずきやすい点までまとめます。

> 画面はPixel 8a／Android 16、TJA Pocket 0.1.8（検証版）で撮影しました。ストアで配信中の版では、ボタンや画面構成が一部異なる場合があります。

この記事の画像では、説明用に用意したオリジナルの短い音源と譜面「MegaDrawk Import Demo」を使っています。第三者の楽曲や譜面は使用していません。

画像はタップすると大きく表示できます。細かい文字が読みにくいときに使ってください。

## 先に用意するもの

音付きで遊ぶには、基本的に次の2つが必要です。

- **譜面ファイル（.tja）**：曲名やテンポ、音符の配置などが書かれたファイル。
- **音源ファイル**：譜面が指定している音声ファイル。この記事では `demo.wav` を使います。

譜面と音源は、元のフォルダ構成を保ったまま用意してください。説明用サンプルは、次のような構成です。

[![MegaDrawk_Import_Demoフォルダの中に、譜面のdemo.tjaと音源のdemo.wavを置く構成図](/blog-assets/2026-10-26-tjapocket-song-import/00-folder-layout.svg)](/blog-assets/2026-10-26-tjapocket-song-import/00-folder-layout.svg)

この譜面には `WAVE:demo.wav` と書かれています。譜面だけを移動したり、音源の名前だけを変えたりすると、音源が見つからなくなります。画像などを参照する譜面の場合は、そのファイルも一緒に用意します。

手順を試してみたい方は、[記事用サンプルのZIP（約530 KiB）](/blog-assets/2026-10-26-tjapocket-song-import/MegaDrawk_Import_Demo.zip)を使えます。中身はオリジナルの合成音源、譜面、説明ファイルです。

使う曲や譜面は、ご自身で制作したものや、利用が認められているものを用意してください。

## ZIPから曲を追加する

ZIPがある場合は、先に解凍しなくても取り込めます。スマートフォン内の、あとで見つけやすい場所に保存しておきましょう。ここでは「Download」に保存しています。

### 1. 設定から「曲管理」を開く

選曲画面の歯車ボタンで設定を開き、右上の **「曲管理」** を押します。

[![設定画面の右上に「ファイル管理」と「曲管理」が並んでいる](/blog-assets/2026-10-26-tjapocket-song-import/01-settings.png)](/blog-assets/2026-10-26-tjapocket-song-import/01-settings.png)

### 2. 「追加」から「ZIPを取り込む」を選ぶ

曲管理画面の右上にある **「追加」** を押し、**「ZIPを取り込む」** を選びます。

[![曲管理の「追加」メニューに「ZIPを取り込む」「フォルダを取り込む」などが表示されている](/blog-assets/2026-10-26-tjapocket-song-import/02-add-menu.png)](/blog-assets/2026-10-26-tjapocket-song-import/02-add-menu.png)

### 3. 保存したZIPを選ぶ

Androidのファイル選択画面が開いたら、ZIPを保存した場所に移動して選びます。この記事では `MegaDrawk_Import_Demo.zip` を選びます。

[![Androidのファイル選択画面で、MegaDrawk_Import_Demo.zipとMegaDrawk_Sample_Skin.zipが表示されている](/blog-assets/2026-10-26-tjapocket-song-import/03-file-picker.png)](/blog-assets/2026-10-26-tjapocket-song-import/03-file-picker.png)

複数の種類のZIPを同じフォルダに置いている場合は、ファイル名で選び分けてください。ファイル名が分かっているときは、右上の検索から探すこともできます。

### 4. 取り込み内容を確認して追加する

ZIPの読み込みが終わると、保存先、曲数、重複、不足ファイルの数が表示されます。

[![取り込み内容に「保存先: 標準」「曲: 1」「重複: 0」「不足ファイル: 0」と表示され、下に「追加」ボタンがある](/blog-assets/2026-10-26-tjapocket-song-import/04-import-preview.png)](/blog-assets/2026-10-26-tjapocket-song-import/04-import-preview.png)

このサンプルでは **「曲: 1」「重複: 0」「不足ファイル: 0」** になっています。内容を確認して **「追加」** を押してください。

不足ファイルがある場合は、いったん「戻る」で閉じて、音源などがそろっているかを確認しましょう。

### 5. 追加した曲を確認する

取り込み結果に **「追加: 1 曲」** と表示されたら、**「追加した曲を見る」** を押します。

[![取り込み結果に「追加: 1 曲」「スキップ: 0 曲」と表示され、「追加した曲を見る」ボタンがある](/blog-assets/2026-10-26-tjapocket-song-import/05-import-result.png)](/blog-assets/2026-10-26-tjapocket-song-import/05-import-result.png)

曲管理の一覧に曲名が表示されれば、取り込みは完了です。曲数が多いときは、上の検索欄で曲名を絞り込めます。

[![曲管理の一覧に、取り込んだMegaDrawk Import Demoと、アプリ同梱のSample Scoreが表示されている](/blog-assets/2026-10-26-tjapocket-song-import/06-imported-songs.png)](/blog-assets/2026-10-26-tjapocket-song-import/06-imported-songs.png)

最後に「戻る」で設定へ戻り、さらに選曲画面へ戻ります。追加した曲を選び、難易度を決定して、音源と譜面が読み込まれることを確認してください。

## 解凍済みのフォルダから追加する

すでに譜面と音源がフォルダにまとまっている場合は、ZIPに圧縮し直す必要はありません。

1. 設定から「曲管理」を開きます。
2. 「追加」→ **「フォルダを取り込む」** を選びます。
3. Androidのフォルダ選択画面で、譜面と音源が入っているフォルダを指定し、アクセスを許可します。
4. 取り込み内容を確認して「追加」を押します。

ZIPから取り込む場合と同じように、譜面と音源の位置関係を保っておくのがポイントです。

## 元のフォルダを参照して使う

曲を保存している場所をそのまま利用したい場合は、**「参照フォルダを登録」** を使えます。

「追加」→「参照フォルダを登録」を開き、表示されたフォルダ一覧の「追加」から対象フォルダを選んで、アクセスを許可します。

| 方法                    | 使い分け                                   |
| ----------------------- | ------------------------------------------ |
| ZIP・フォルダを取り込む | 内容を取り込み先へコピーして使いたいとき。 |
| 参照フォルダを登録      | 元の保存場所を参照元として使いたいとき。   |

参照元のフォルダを移動したり、アクセス権を取り消したりすると、読み込めなくなることがあります。元のフォルダの内容を変更したあとに反映されない場合は、曲管理の「曲フォルダ」→「フォルダを管理」から登録済みのフォルダを選び、「再読み込み」を試してください。

## 重複した曲を追加しようとしたとき

すでに同じ曲を取り込んでいるZIPを選ぶと、取り込み内容に **「重複: 1」** と表示されます。

[![重複がある場合の取り込み内容。重複: 1と表示され、「別名で追加」「重複をスキップして追加」が選べる](/blog-assets/2026-10-26-tjapocket-song-import/07-duplicate.png)](/blog-assets/2026-10-26-tjapocket-song-import/07-duplicate.png)

この場合は、次のどちらかを選べます。

- **別名で追加**：既存の曲を残したまま、別の名前で追加する。
- **重複をスキップして追加**：重複した曲を追加せず、ほかの曲だけを取り込む。

同じ曲を意図的に2つ持ちたい場合以外は、「重複をスキップして追加」を選ぶと一覧が増えすぎません。

## うまく追加できないとき

### ZIPを選んでも曲が見つからない

ZIPの中に `.tja` ファイルがあるか確認してください。音源だけのZIPは、譜面として取り込めません。パスワード付きZIPは取り込みに対応していません。

### 「不足ファイル」が表示される・音が出ない

譜面が指定しているファイル名と、実際の音源ファイル名を確認してください。サンプルなら `WAVE:demo.wav` に対応する `demo.wav` が、譜面と同じフォルダに必要です。画像などを指定している場合は、そのファイルも確認します。

不足がないのに聞こえない場合は、端末のメディア音量と、アプリの設定にある音量も確認してみてください。

### 同じ曲をもう一度取り込んでしまった

取り込み内容の「重複」を確認してください。重複がある場合は **「重複をスキップして追加」** を選べます。取り込み結果の「スキップ」が増えていても、すでに曲が入っている場合があります。

### 追加したはずの曲が一覧にない

曲管理の検索文字やジャンルの絞り込みを解除し、取り込み先が合っているか確認してください。取り込み結果の **「追加した曲を見る」** からたどることもできます。

### フォルダを選べない・アクセスできない

Androidのバージョンによっては、ストレージの最上位やDownloadフォルダそのものを、フォルダ選択で指定できない場合があります。曲用のサブフォルダを用意して選ぶか、ZIPのファイル選択で取り込んでください。

参照フォルダの権限が切れている場合は、そのフォルダを選び直してアクセスを許可します。取り込みでエラーが出る場合は、端末の空き容量も確認してください。

まずは1曲から試して、音が出て遊べるところまで確かめてみてください。それでは、よい演奏を！
