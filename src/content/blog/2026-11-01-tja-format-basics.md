こんにちは、Drawkです。

TJAは、太鼓系のリズムゲームで広く使われている譜面ファイルの形式です。拡張子は`.tja`で、中身はテキストです。専用のエディタがなくても、メモ帳などのテキストエディタで開いて編集できます。

この記事では、TJAファイルを読んだり、簡単な譜面を書いたりするために必要な基本を整理します。TJA Pocketで遊ぶ場合も、譜面の中身が分かると、原因の切り分けがしやすくなります。

> この記事はTJA形式の一般的な仕様をまとめたものです。対応する命令や解釈は、使用するアプリやシミュレーターによって異なる場合があります。

## TJAファイルの構成

TJAファイルは、大きく分けて**ヘッダー**と**譜面本体**の2つで構成されます。

```text
TITLE:Example Song
SUBTITLE:--Demo
BPM:150
WAVE:example.ogg
OFFSET:-0.5
COURSE:Oni
LEVEL:8

#START
1000100010001000,
1000100010001000,
#END
```

`#START`から`#END`までが譜面本体です。ヘッダーは、曲名・音源・テンポなど、譜面全体に関わる情報を書きます。

## ヘッダーの主な項目

よく使うヘッダー項目は次のとおりです。

| 項目        | 内容                           | 例                   |
| ----------- | ------------------------------ | -------------------- |
| `TITLE`     | 曲名                           | `TITLE:Example Song` |
| `SUBTITLE`  | サブタイトル。作者名や出典など | `SUBTITLE:--Demo`    |
| `BPM`       | 開始時のテンポ                 | `BPM:150`            |
| `WAVE`      | 音源ファイル名                 | `WAVE:example.ogg`   |
| `OFFSET`    | 音源と譜面の開始位置の調整     | `OFFSET:-0.5`        |
| `DEMOSTART` | 選曲画面の試聴開始位置（秒）   | `DEMOSTART:10.0`     |
| `COURSE`    | 難易度                         | `COURSE:Oni`         |
| `LEVEL`     | 難易度の数値                   | `LEVEL:8`            |
| `BALLOON`   | 風船の必要打数                 | `BALLOON:10,15`      |

`WAVE`に書いたファイル名は、実際の音源ファイル名と完全に一致させます。拡張子も含めて一致していないと、音源が見つからず、無音になります。

`OFFSET`は、音源の再生位置と譜面の開始位置を合わせるための値です。符号の向きや解釈は実装によって異なる場合があるため、使用するアプリで実際に確認してください。

## 音符は数字で書く

譜面本体では、音符を数字で表します。

| 数字 | 意味                 |
| ---- | -------------------- |
| `0`  | 何も置かない         |
| `1`  | ドン（赤）           |
| `2`  | カッ（青）           |
| `3`  | 大ドン（大音符・赤） |
| `4`  | 大カッ（大音符・青） |
| `5`  | 連打の開始           |
| `6`  | 大連打の開始         |
| `7`  | 風船の開始           |
| `8`  | 連打・風船の終了     |
| `9`  | くす玉の開始         |

たとえば、`1000100010001000`は、16分のマスの中に4分音符のドンを4つ置いた状態です。

## 小節はカンマで区切る

TJAでは、**カンマ（`,`）が小節の区切り**です。1小節の中の文字数は自由で、文字数によって譜面の細かさが変わります。

4分の4拍子の場合、16文字なら16分音符のマス、48文字なら16分音符と3連符の両方を表せるマスになります。文字数が多いほど、細かいリズムを書きやすくなります。

```text
#START
1000100010001000,
1000100010001000,
#END
```

上の例は、2小節分です。1小節目と2小節目をそれぞれカンマで区切っています。

休符だけの小節は、カンマだけの行で表せます。

```text
,
```

小節の途中で改行しても、カンマが来るまでは同じ小節として扱われます。長い小節を複数行に分けて書くと、見通しがよくなります。

## よく使う命令

`#START`と`#END`の間には、`#`で始まる命令を書けます。

### BPMを変更する

```text
#BPMCHANGE 180
```

その位置以降のテンポを変更します。曲の途中でテンポが変わる場合に使います。

### 拍子を変更する

```text
#MEASURE 3/4
```

小節の拍子を変更します。小節の先頭に置くのが基本です。

### スクロール速度を変更する

```text
#SCROLL 1.1
```

音符の流れる速さを変更します。音符のタイミング自体は変わりません。演出や見やすさの調整に使います。

### ゴーゴータイムを指定する

```text
#GOGOSTART
#GOGOEND
```

ゴーゴータイムの開始と終了を指定します。

### 小節線を消す

```text
#BARLINEOFF
#BARLINEON
```

小節線の表示を一時的に消したり、戻したりします。音符のタイミングには影響しません。

### 譜面分岐を書く

```text
#BRANCHSTART p, 65, 90
#N
（ふつうの譜面）
#E
（達人の譜面）
#M
（魔境の譜面）
#BRANCHEND
```

演奏の精度などに応じて、譜面を分岐させます。分岐の条件や判定方法は実装によって異なります。

## コメントと文字コード

`//`以降はコメントとして扱われます。譜面のメモを残したいときに使えます。

```text
// サビ前の譜面
1000100010001000,
```

文字コードは、UTF-8で保存すると文字化けしにくくなります。配布元のファイルがShift-JISの場合もあるため、曲名が文字化けするときは、保存されている文字コードを確認してください。

## 書き間違いやすいポイント

- 小節の最後にカンマを付け忘れる
- `WAVE`のファイル名と実際の音源名が一致していない
- 1小節の文字数と、書きたいリズムの分割数が合っていない
- `#START`と`#END`の対応が取れていない
- 全角の数字や記号を混ぜてしまう

特に、カンマの付け忘れは譜面全体のずれにつながります。編集したら、アプリで読み込み、最初の小節と曲の終わりを確認してください。

## TJA Pocketで確認する

TJA Pocketでは、TJAファイルと音源を読み込んで演奏できます。譜面を編集したら、アプリで実際に読み込み、音とノーツの位置を確認するのが確実です。
